# Calme — iOS Caregiver Support Prototype

Calme is a SwiftUI prototype designed to help caregivers choose calming strategies for autistic children. It uses a quick check-in and personalized suggestions based on the current situation and previous feedback.

**Technology:** Swift, SwiftUI, Core ML (model included in the original project archive).

## Concept
Caregivers identify a trigger and intensity, review suggested strategies, and record whether a strategy helped. Examples include finding a quiet place, using headphones, breathing exercises, and gentle movement.
